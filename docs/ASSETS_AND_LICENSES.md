# Assets, licenses, and competition-sharing notes

## Repository code

Original code in this repository is released under the MIT License in the repository root.

## Competition data

The DaT Parkinson’s Challenge dataset is not redistributed. Obtain authorized access from [DrivenData](https://www.drivendata.org/competitions/311/dat-parkinsons-challenge/) and follow the current competition/data terms. This repository’s MIT License does not apply to the data.

Competition rules and page content can change. Review the current [rules](https://www.drivendata.org/competitions/311/dat-parkinsons-challenge/page/970/) and [code-execution instructions](https://www.drivendata.org/competitions/311/dat-parkinsons-challenge/page/989/) before sharing or submitting. Public release is intentionally separated from private collaboration and from redistribution of challenge data.

## DINOv2

The DINOv2 ViT-S/14 checkpoint and upstream implementation are not included. Obtain them from the [official DINOv2 repository](https://github.com/facebookresearch/dinov2), verify the exact asset and its license, preserve required notices, and record a local digest. This repository’s MIT License does not relicense third-party weights or source.

## DINOv3 and other reviewed methods

DINOv3-related weights/source are not included. Historical experiments that referenced DINOv3 do not establish prize-license eligibility for every upstream asset. The Phase66 research note links other papers and repositories for comparison; their presence in the literature review is not an endorsement, bundled dependency, or license grant.

## Release manifest

`PUBLIC_RELEASE_MANIFEST.json` records the SHA-256 and size of every checked-in public file except Git metadata and the manifest itself. It is an integrity aid, not a software bill of materials or legal opinion.
